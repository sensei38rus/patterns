
| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **1. Домен: Складской учет** | | |
| **Группа номенклатуры** | Классификатор/категория, к которой относятся элементы номенклатуры (например: «Мясные», «Молочные», «Заготовки», «Упаковка»). | • Содержит множество **Номенклатур**.<br>• Может участвовать в **Инвентаризации** (частичной). |
| **Номенклатура** | Справочник товаров, ингредиентов, полуфабрикатов, готовых блюд и упаковки. | • Входит в **Группу номенклатуры**.<br>• Связана с **Остатками на складе**.<br>• Входит в состав **Технологических карт**.<br>• Фигурирует в **Заказах** (на доставку, пополнение, производство).<br>• Используется в актах **Приготовления/Выпуска/Утилизации**.<br>• Блокирует удаление при наличии движения. |
| **Помещение / Точка** | Физическое подразделение компании (Ресторан, Центральный производственный цех). Содержит тип работы (доставка/комбинированный/зал). | • Связано со **Складами**.<br>• Связано с **Районами доставки**.<br>• Привязано к **Заказам**. |
| **Склад** | Место хранения номенклатуры (например: «Холодильник мяса», «Склад заготовок», «Основной склад ресторана №1»). | • Привязан к **Помещению / Точке**.<br>• Хранит **Остатки номенклатуры**.<br>• Участвует в документах **Инвентаризации**, **Выпуска**, **Списания**. |
| **Остаток номенклатуры** | Регистр учета количества товара/продукта на конкретном складе с учетом типа списания (блокировка при недостаче / под сальдо). | • Связан с **Номенклатурой**.<br>• Связан со **Складом**. |
| **Инвентаризация (Плановая / Частичная)** | Документ сверки фактического и учетного количества номенклатуры на складе. | • Проводится по конкретному **Складу**.<br>• Ссылается на **Группу номенклатуры** (при частичной) или **Номенклатуру** (при плановой).<br>• Фиксирует **Сотрудника (ответственного)**. |
| **2. Домен: Производственный учет** | | |
| **Технологическая карта (Рецептура)** | Описание состава и норм расхода ингредиентов/полуфабрикатов для приготовления блюда или полуфабриката. Может быть составной. | • Включает в себя элементы **Номенклатуры**.<br>• Может включать другие **Технологические карты** (составная рецептура).<br>• Используется в **Приготовлении полуфабриката / блюда** и **Выпуске продукции**. |
| **Приготовление полуфабриката / блюда** | Операционный документ, фиксирующий факт производства заготовки или блюда, списания сырья и прихода готовой продукции. | • Ссылается на **Технологическую карту**.<br>• Списывает/приходует **Номенклатуру** со **Склада**.<br>• Указывает **Сотрудника (ответственного)**. |
| **Выпуск продукции** | Документ о завершении производства партии продукции и ее передаче на склад/в ресторан. | • Связан с **Заказом на производство**.<br>• Фиксирует **Номенклатуру** и **Склад**.<br>• Указывает **Сотрудника (ответственного)**. |
| **Утилизация продукции** | Документ списания испорченной или просроченной продукции/сырья. | • Списывает **Номенклатуру** со **Склада**.<br>• Фиксирует **Сотрудника (ответственного)**. |
| **3. Домен: Курьерская служба** | | |
| **Район доставки** | Географическая зона обслуживания с указанием фиксированной стоимости доставки. | • Привязан к ближайшим **Помещениям/Ресторанам**.<br>• Используется в **Заказах на доставку**. |
| **Меню доставки** | Специальный каталог блюд, доступных для заказа с доставкой, включающий стоимость и обязательную упаковку. | • Связан с позициями **Номенклатуры**.<br>• Автоматически привязывает **Номенклатуру (упаковку)** к позиции меню. |
| **4. Домен: Финансовый учет и взаиморасчеты** | | |
| **Группа контрагентов** | Классификатор юридических лиц и партнеров (например: «Поставщики мясных продуктов», «Арендаторы»). | • Содержит **Контрагентов**. |
| **Контрагент** | Сторонняя организация / юридическое лицо, с которым ведутся финансовые взаиморасчеты. | • Входит в **Группу контрагентов**.<br>• Связан с **Финансовыми документами (Поступление / Списание)**. |
| **Тип оплаты** | Справочник способов расчета (наличные, банковский перевод, и др.). | • Используется в документах **Поступления** и **Списания**. |
| **Поступление / Списание ДС** | Документы учета движения денежных средств. | • Связаны с **Контрагентом**.<br>• Указывают **Тип оплаты**.<br>• Фиксируют **Сотрудника (ответственного)**. |
| **5. Домен: Учет персонала** | | |
| **Сотрудник** | Карточка работника компании с указанием личных данных, должности и категории. | • Входит в **Категорию сотрудников**.<br>• Привязан к **Графику работы**.<br>• Фиксируется как ответственный во всех **Документах** (складских, финансовых, оперативных).<br>• Связан с **Учетом рабочего времени / Сменами**. |
| **Категория сотрудников** | Классификатор направлений деятельности («Производство», «Обслуживание», «Управление»). | • Группирует **Сотрудников**.<br>• Определяет правила назначения **Графика работы**. |
| **График работы** | Нормативный график смен/часов (сменный до 8 ч для производства; 8-часовой 5/2 для остальных). | • Назначается **Сотруднику**.<br>• Используется для расчета переработок в **Учете рабочего времени**. |
| **Учет рабочего времени (Смена)** | Запись о фактическом начале и завершении работы сотрудника, фиксирующая обычные часы и переработку (для расчета по двойному тарифу). | • Связана с **Сотрудником**.<br>• Сверяется с **Графиком работы**. |
| **6. Домен: Оперативный контроль и заказы** | | |
| **Заказ на доставку** | Заявка клиента на доставку еды. Автоматически маршрутизируется на ближайший ресторан. | • Связан с **Районом доставки**.<br>• Связан с **Помещением (Рестораном)**.<br>• Содержит элементы из **Меню доставки**.<br>• Указывает **Сотрудника (ответственного)**. |
| **Заказ на пополнение склада** | Заявка администратора ресторана в центральный производственный цех на привоз заготовок/продуктов к началу дня. | • Связан с **Помещением-заказчиком** и **Помещением-исполнителем**.<br>• Содержит перечень **Номенклатуры**.<br>• Указывает **Сотрудника (ответственного)**. |
| **Заказ на производство** | План/задание для производственного цеха на приготовление заготовок или полуфабрикатов. | • Формируется на основе **Заказов на пополнение**.<br>• Включает перечень **Номенклатуры**.<br>• Связан с **Выпуском продукции**.<br>• Указывает **Сотрудника (ответственного)**. |
