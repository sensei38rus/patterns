# Письмо

Привет, бро!
Нашей команде внось нужна твоя экспертиза!

Команда готовится к первому показу нашего решения. 
Мы договорились создать простую систему отчетности.
Основа для отчетов дожна быть любая доменная модель (единица измерения, рецепт и прочее)
и формат: `TXT`, `MARKDOWN`, `CSV`

Мы создали методы:

1. `Получить отчет по умолчанию`

- http://0.0.0.0:8080/api/get_default_report?unique_code=333&entity=range_model

2. `Получить список сущностей`

- http://0.0.0.0:8080/api/get_entities

**И у нас ничего не работает толком** , а времени в обрез.

Нам не хвататет:
- Метод для получения типизированного отчета
- Метод для отображения списка форматов

Так же, разработанные методы возвращают либо ошибку, либо "ерунду".

**Вся надежда лишь на тебя!**
